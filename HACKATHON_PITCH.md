# 🌞 SolarDash - Smart Energy Management System
> **Hackathon Pitch & Project Overview**

## 💡 The Problem
Renewable energy adoption is growing, but **Energy Literacy** is low. Users install solar panels but don't know *when* to use their appliances to maximize savings. Standard monitoring apps are passive—they just show graphs.

## 🚀 The Solution: SolarDash
SolarDash is not just a dashboard; it's an **Active Energy Assistant**. It uses real-time logic to predict solar generation vs. consumption and provides *actionable advice* to the user.

### 🔑 Key Differentiators (Why We Win)
1.  **Grid Intelligence Simulation** (Unique Feature):
    - Unlike standard apps, SolarDash simulates **Grid Outages**.
    - It visualizes how the system behaves in "Battery Backup Mode" (Gray-scale UI with critical alerts), teaching users about energy resilience.
    
2.  **Smart Appliance Alerts**:
    - Instead of just "3.5kWh produced", we say: *"Wash clothes now to save $2.50"* or *"Wait until 2 PM"*.
    - Context-aware recommendations based on **Time of Day** + **Surplus Energy**.

3.  **Glassmorphism UI**:
    - A stunning, heavy-glass UI that looks futuristic and premium (Apple visionOS inspired).
    - Fully responsive with Dark/Light mode support.

## 🛠️ Technical Stack
- **Frontend**: React + Vite (Fast, efficient)
- **Styling**: Pure CSS Modules + Variables (Performance optimized, no heavy framework overhead)
- **Backend**: Node.js + Express (Scalable API)
- **Security**: `bcrypt` hashing for secure user data.
- **Data Visualization**: Recharts for beautiful, responsive energy graphs.

## 🔮 Future Roadmap
1.  **AI Integration**: Use TensorFlow.js to learn user habits (e.g., "You usually do laundry on Sundays").
2.  **IoT Connection**: Directly control smart plugs (TP-Link/Sonoff) to auto-start appliances when surplus > 2kW.
3.  **Community Grid**: Share excess energy with neighbors (Simulated Blockchain marketplace).
